## Правила оценивания в 1 модуле

### За каждую задачу начисляется от нуля до максимального кол-ва баллов. Задания защищаются лично, преподаватели могут (и будут) задавать вопросы.

### Количество баллов на оценку.
- Оценка 3 (4-5 по десятибальной) - >= 20 баллов
- Оценка 4 (6-7 по десятибальной) - >= 25 баллов
- Оценка 5 (8-9 по десятибальной) - >= 30 баллов
- 10 баллов по десятибальной - за особые достижения
