# Linux System Programming Labs

![C/C++](https://img.shields.io/badge/C%2FC%2B%2B-Linux-00599C?logo=linux&logoColor=white)
![POSIX](https://img.shields.io/badge/API-POSIX-333333)
[![MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Учебные проекты по системному программированию в Linux на C и C++: процессы, файловые операции, IPC, сетевое взаимодействие и низкоуровневая разработка.

## Первый модуль

| Задача | Описание |
|---|---|
| `filestat` | Подсчёт файлов разных типов в каталоге |
| `hide` | Перемещение файла в скрытый каталог |
| `launcher` | Запуск процесса с перенаправлением stdout и stderr |
| `nohup` | Запуск процесса без управляющего терминала |
| `stash` | Временное искажение и восстановление типа файла |
| `stego` | Добавление, чтение и удаление данных в JPEG |

## Второй модуль

| Задача | Описание |
|---|---|
| `1shmem` | Producer–consumer через разделяемую память |
| `chat` | Консольный UDP broadcast-чат |
| `kernel` | Минимальное загружаемое ядро x86 |
| `kotichi` | Параллельная загрузка изображений и создание коллажа |

В остальных каталогах находятся условия для RPC-сервиса, watchdog и модулей ядра.

## Требования

- Linux;
- GCC/G++ с поддержкой C++17;
- POSIX API;
- дополнительные зависимости указаны в README конкретных задач.

Каждая лабораторная является отдельной программой. Команды сборки и запуска приведены рядом с исходниками.

## Проверка

Основные пользовательские программы проходят проверку GCC с `-std=c++17 -Wall -Wextra -Wpedantic`. Задачи ядра и модулей Linux требуют отдельного toolchain и окружения, описанного рядом с исходниками.
