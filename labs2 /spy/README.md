## Spy

Напишите модуль ядра - клавиатурный шпион. Модуль должен считывать ввод с клавиатуры и сохранять его в памяти.
Необходимо разделять введенные символы из различных процессов. Доступ к сохраненным данным реализуйте через символьное устройство. Устройство должно поддерживать команды:
list - получение идентификаторов процессов и имен программ, ввод которых был перехвачен
read <N> - получение сохраненных символов по заданному идентификатору.

**Максимальный балл — 50**
