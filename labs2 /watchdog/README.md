## Watchdog

Напишите модуль ядра, предоставляющий функциональность сторожевого таймера. Модуль должен регистрировать символьное устройство, запоминающее идентификаторы всех открывших его процессов и отправлять процессам заданный сигнал при отсутствии операций с устройством в течении заданного времени. Таймаут и номер сигнала передайте через параметры модуля.

**Максимальный балл — 40**
